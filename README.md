# HGP_thesis_scripts
Python code supporting the Manchester Metropolitan University DClinSci research project

Title

RH VARIANTS IN ENGLISH HAEMOGLOBINOPATHY PATIENTS; 
A NESTED STUDY OF THE HAEMOGLOBINOPATHY GENOTYPING PROJECT TO DETERMINE RH VARIANT FREQUENCIES, THE RATE OF PHENOTYPE – GENOTYPE DISCREPANCIES AND ENSURING OPTIMUM PRODUCT SELECTION.

Author 
Shane Grimsley

Purpose
This repository contains the Python notebooks developed to support the analyses presented in the associated PhD thesis submitted to Manchester Metropolitan University.
Software Environment
- Python 3.12.7
- Jupyter Notebook 7.2.2
- JupyterLab 4.2.5

Python Dependencies
- pandas
- numpy
- os
A complete version-controlled dependency list is also provided in requirements.txt.

Data Availability
The original research dataset is not included in this repository because it contains confidential personal and medical information relating to NHS patients. Access to the data was restricted to authorised NHS Blood and Transplant personnel in accordance with a data sharing agreement and applicable ethical, confidentiality and data protection requirements.

Thesis Reference
The workflow implemented by these notebooks is described in Chapter 5 of the associated thesis.
